# PathLab icon

![PathLab icon](pathlab-model59.svg)

Use `pathlab-model59.svg` as the canonical artwork. `pathlab-model59.png` is a
768-by-768 transparent fallback for applications that cannot display SVG.
Preserve the square aspect ratio and clear space; do not stretch the image.
All four nodes use matching square boxes with rounded corners. The outlines
and letters are blue for X, M and Y, and gold for W. Node interiors
and the background are transparent, without blue or gold fills. A light
background is recommended for contrast.

This original schematic is inspired by the conceptual structure commonly called
PROCESS Model 59: X -> M -> Y and X -> Y, with W moderating all three paths.
It identifies PathLab; it does not select a model, represent the currently
fitted graph, or imply affiliation with PROCESS or Andrew F. Hayes.

The artwork is covered by the module's GPL version 2 or later license.
It is included in the installed R package's `branding` directory and in the
standalone module source. Documentation uses the SVG directly. The tested
jamovi 2.7.39 host does not support a custom module-supplied ribbon icon;
its generic ribbon icon remains unchanged. Do not patch host application assets.
